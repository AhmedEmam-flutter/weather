# 🌦 Weather App

A simple and clean Flutter weather application using WeatherAPI. Users can view the current weather by searching for any region.

---

## 📌 Features

- Fetches live weather data using WeatherAPI
- Search by city or region
- Displays temperature, humidity, and weather description
- Clean UI using Flutter and Bloc state management

---

## 📂 Project Structure

lib/
├── core/ # App colors, constants, etc.
├── home/
│ ├── data/ # Models, data sources, repositories
│ ├── domain/ # Entities, use cases
│ └── presenter/ # Cubit controllers and UI screens
└── main.dart # App entry point


📦 Dependencies
flutter_bloc
-http
-equatable


🛠 State Management
This project uses Cubit (Bloc) for managing UI state and API interactions.
